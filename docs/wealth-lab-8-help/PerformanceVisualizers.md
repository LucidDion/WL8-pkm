# Performance Visualizers
After you backtest a trading [Strategy](Strategies), you can click the **Backtest Results** tab and start exploring the performance results. Wealth-Lab uses **Performance Visualizers** to show you how well your Strategy performed on historical data. Each **Performance Visualizer** occupies its own tab in the Strategy's **Backtest Results** page. 

Wealth-Lab comes with the following **Performance Visualizers**, but you might have more depending on the [Extensions](Extensions) you have installed.

 - Metrics Report
 - Equity 
 - Drawdown 
 - Distributions
 - Positions
 - Periodic Returns
 - Monthly Returns 
 - Rolling Profit
 - By Symbol
 - [Weights (*Rotation*)](https://www.youtube.com/watch?v=qoqrw6hyqKY&t=145s)
 - Profit Curves (*MetaStrategy*)

---
## Controlling Performance Visualizers
In the [Backtest Preferences](BacktestPreferences) interface you can control which **Performance Visualizers** appear in the [Strategy](Strategies) window. You can also change their order by dragging and dropping them in the list.
