## Periodic Returns

This visualizer allows you to see the strategy performance broken down by day, week, month, quarter, or year. The monthly returns are simply the account's equity value on the last day of the month minus the value on the last day of the previous month. Consequently, the return value is calculated by the change in the equity curve, not by the sum of exits in the specified period. You have the choice of displaying your data in percentage (default) or dollar representations using the button on the toolbar.

Available when *Daily, Monthly or Quarterly* analysis period is chosen, the **Group by** button allows to group the results by Day of Week (*Monday, Tuesday*...), Week Number (*0, 1,...52* and 53 in leap years) Month of Year (*January, February*...) and Quarter of Year (*Q1, Q2*...) across all observations, consequently.

**Average Return**  
The average percentage return for the specified period.  For example, if you select Monthly, the percentage return by month is calculated and its average value is reported here. 

**Std Deviation of Returns**  
The standard deviation of the individual percentage returns.

**Maximum/Minimum Return**  
These values indicate the best and worst returns recorded during the simulation period on a by-period basis. 

**Consecutive Profit/Loss**  
The maximum number of consecutive profitable and unprofitable periods are reported here.

**Observations**  
Number of periods
