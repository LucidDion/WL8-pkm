# Metric Column Preferences

 - [take me there now](action:MetricPreferences)

Set up your preferred metrics to be used and shown for [Optimizations](Optimization) and [Strategy Rankings](StrategyRankings) by dragging them one-by-one from the list of installed ScoreCards on the left to the Metric Columns list on the right.  

### Removing Metrics
Remove metrics by dragging items back to the ScoreCards on the left.  You can quickly remove multiple items by selecting one or more metrics and then right-click to **Delete Selected Metrics**.   

### Order the list
Using drag and drop, put the list in the order you want the columns to be displayed in [Optimizations](Optimization) and [Strategy Rankings].
