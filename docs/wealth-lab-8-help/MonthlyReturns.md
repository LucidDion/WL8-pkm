## Monthly Returns

This visualizer allows you to see the strategy performance broken down by month. The monthly 
returns are simply the account's equity value on the last day of the month minus the value 
on the last day of the previous month. Consequently, the return value is calculated by the 
change in the equity curve, not by the sum of exits in the specified period. The data is 
displayed in percentages in a tabular format. Additionally, the average monthly return 
and the number of average trades per month is indicated.
