# Symbol by Symbol Optimization

In this mode, a complete [Standard Optimization](StandardOptimization) is run on each Symbol in the DataSet. The resulting list displays the best Parameter values for each Symbol, based on whatever Metric you specify in the two combo boxes. For example, the selection below causes the list to display the Parameter values for each Symbol that resulted in the **Highest APR**. You can select any of the Metrics that had been chosen in Preferences, [Performance Metrics](MetricPreferences).

![Symbol by Symbol Optimization](https://www.wealth-lab.com/images/WLHelp/SymBySym.png)

Once the Optimization is complete, and the per-Symbol Parameter values have been obtained, use the various right-click menu items on the list to do one of the following:

 - Assign a **single Symbol's** Parameter value listed here as the [Preferred Values](PreferredValues) for **all Symbols** in the DataSet.
 - Assign the **selected Symbols'** Parameter values listed here as their [Preferred Values](PreferredValues).
 - Assign **all the Symbols'** Parameter values listed here as their [Preferred Values](PreferredValues).
