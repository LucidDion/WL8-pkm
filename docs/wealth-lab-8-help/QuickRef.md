# QuickRef

 - [take me there now](action:QuickRef)

The **QuickRef** is a help system integrated into the [C# Code-Based Strategy](CSharpCodeBased) code editor. It provides documentation on the .NET classes, properties, and methods you'll work with when programming Wealth-Lab [Strategies](Strategies) by hand. 

---
## Integrated
When you **click on keywords** in the C# code Editor the corresponding **QuickRef entry** will appear.

---
## Examples
Most QuickRef entries contain **complete example code**. You can load the example Strategy into a new window with the click of a button.

## Search
Use the search interface to search the QuickRef's contents for specific keywords.
