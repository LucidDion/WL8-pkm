# Navigating Wealth-Lab
The Wealth-Lab user interface is divided into the following sections:

 - **Menu** - access to all functions available.
 - **Toolbar** - shortcut buttons to access frequently used functions.
 - **Nav Pane** - occupies the left side panel and lets you change views to control various settings and access different collections of items such as [Indicators](Indicators) and [Building Blocks](BuildingBlocks). Each **Nav Pane** view is described in the help pages directly under this one.
 - **Window Client Area** - holds the various tool windows such as the [Chart](Chart) window and [Strategy](Strategies) window that you will open while working with Wealth-Lab.
 - **Data Panel** - occupies the right side of the main window. The Data Panel is initially hidden, but you can make it visible via the **View** menu. It displays price/volume and indicator values as you move the mouse along a chart.
 - **Drawing Toolbar** - snapped to the right edge of the window, contains various drawing tools such as trendlines and volume profile that you can draw onto a chart.
 - **Status Bar** - occupies the bottom of the interface and shows you important status information, including your license, and whether or not you are using Wealth-Lab as an **Administrator**.

## File Menu
There are a few useful features tucked away in Wealth-Lab's **File** menu.  These are:
 - **Offline Mode** - turn this on if you do not have an internet connection. It prevents data requests from being made, and will increase performance when working without internet.
 - **Expert Mode** - turn this on to hide certain help text sprinkled throughout the user interface and to configure default behaviors, like hiding the chart toolbar for new windows. Once you're familiar with the product you won't need extra help text, so you'll have more screen real estate in Expert Mode.
