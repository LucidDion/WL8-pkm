# Strategies

 - [take me there now](action:Strategies)

**Strategies** is a file system of your C# Coded, Building Block, and/or Meta Strategies.  Double click a Strategy to open it, or if you prefer use the right click menu that has other actions and organization options: 
- Open Strategy
- Optimize Strategy 
- Delete Strategy
- Add to Strategy Monitor
- New Folder 
- Delete Folder

Select a Strategy to see its creation date and description (if one exists) displayed in the lower pane. 

## Create New Strategies
Use the New buttons along top row to open a fresh Strategy design window. The icon indicates the type:
- New Building Block Strategy
- New C# Coded Strategy
- New Rotation Strategy
- New MetaStrategy
- New TradeHistory Strategy

Organize your Strategies by creating and saving them to **New Folders**.  

## Strategy Search
It's convenient to use the **Name Filter** and/or **Source Filter** to screen the list by name and/or code, respectively, to quickly find saved Strategies. Folders automatically open when a filter identifies a Strategy matching the text as you type. 

## List and Tree Views
You can switch the view in this pane to a List View and then again back to a Tree View by right clicking and selecting the appropriate option. In the List View, you can sort the Strategies by a number of columns, and generally perform all of the other actions available in the Tree View.
