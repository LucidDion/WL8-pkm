# Markets & Symbols

 - [take me there now](action:MarketsAndSymbols)

The **Markets & Symbols** window lets you examine, configure, and create **Markets** and **Symbols**. 

**Markets** represent exchanges, and specify things like trading hours and time zone. 

**Symbols** are associated with **Markets**, and specify things like point value and decimal precision.
