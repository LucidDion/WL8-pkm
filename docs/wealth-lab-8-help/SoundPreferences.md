# Sound Preferences

 - [take me there now](action:SoundPreferences)

You can control **sounds** for the events listed below.  The Sound Manager will attempt to play all sounds for events triggered without priority. 

- New bar in Streaming Chart
- Order filled in Order Manager
- Save Strategy, Workspace, other
- Signals from Strategy (backtest, non-streaming window)
- Triggered Signal Alarm in Quotes, Streaming Chart, Strategy Monitor

Use the default sounds installed with Wealth-Lab or choose your own sound file  Only **mp3** and **wav** files are supported. 

### Mute Sounds
Temporarily **turn off** all or specified sounds by checking the appropriate box.
