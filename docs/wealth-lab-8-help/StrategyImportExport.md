# Strategy Import and Export

Use the import/export actions to share your strategies with Wealth-Lab users or with the Support team for troubleshooting code. 

---
## Export
Exported strategies are saved to a folder of your choosing with an **XML** suffix (file type) using one of these two methods:

1. Export a Strategy or *folder of Strategies* from the Strategy tree using the right click menu option **Export Strategies**. Exporting a folder will not create a new folder, rather all strategies contained in the folder are exported to the chosen location as individual XML files. 
2. Click the **Export** button in the toolbar of an open Strategy or MetaStrategy window to export it.

---
## Import
Likewise, the following two methods can be used to import an XML or a legacy WL7Strategy file.  If a strategy with the same name already exists, "(Imported)" will be added to the name of the imported Strategy. 

 1. Select the folder to which you want to add the strategy by right clicking and selecting **Import Strategies**. 
 2. Locate the XML/WL7Strategy file using Windows Explorer, drag and drop it onto a Strategy folder. 

---
## Open
*Opening* an exported XML/WL7Strategy is similar to *importing* except the strategy is not named or added to a Strategy folder.  Rather, the strategy is opened, unnamed in a Strategy Window.  This is a convenient way to start new Strategies using different templates, for example.

1. Click **File > Open Exported Strategy** main menu option and locate the strategy to open.  
2. Locate the XML/WL7Strategy file using Windows Explorer, **drag and drop** it onto a main window's *workspace area*.
