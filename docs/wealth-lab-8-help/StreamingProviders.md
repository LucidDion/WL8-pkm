# Streaming Providers

 - [take me there now](action:StreamingData)
 
**Streaming Data Providers** supply streaming data to Wealth-Lab's Streaming tools: [Charts](StreamingCharts), [Quotes/Price Triggers](Quotes) and [Strategy Monitor](StrategyMonitor) windows. Use this view to enter any Provider-Specific Settings for login or other options.

Each Streaming tool has a **Stream** control to select from the list of installed providers. 
After clicking **Stream** you should see the status circle turn green to indicate a successful connection. 

![Streaming Controller](https://www.wealth-lab.com/Images/WLHelp/StreamingController.png)

**Default Streaming Provider**  
You can have multiple **Streaming Providers** running concurrently. The Provider that you last select in a Streaming tool becomes the default Streaming Provider when opening a new Chart or Quotes window, or setting up a new Strategy Monitor item.  

### Streaming Data Testbed
Test the ability to retrieve streaming data from the selected provider using this simple interface. A successful stream will show an updating date/time, price, and last trade size for the selected symbol. 

### Symbol Mappings
You can support streaming for a Historical Provider that uses different symbology by assigning Symbol Mappings. For more information, see Symbol Mappings in the [Order Manager topic](OrderManager).
